# ToDoアプリ

JavaScriptで作成したシンプルなToDoアプリです。

## 概要

- 入力欄にタスクを入力して「追加」ボタンを押すと、タスクがリストに追加されます。
- 追加されたタスクは一覧で表示されます。

## 使い方

1. `todo-app/index.html` をブラウザで開きます。
2. 入力欄にタスクを入力します。
3. 「追加」ボタンをクリックします。
4. タスクがリストに表示されます。

## ファイル構成

- `index.html`: 画面の構造を定義
- `todo-list.js`: タスク追加のロジックを実装
- `README.md`: このドキュメント
