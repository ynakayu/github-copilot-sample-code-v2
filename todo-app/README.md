# ToDoアプリ

JavaScriptで作成したシンプルなToDoアプリです。

## 概要

- 入力欄にタスクを入力して「追加」ボタンを押すと、タスクがリストに追加されます。
- 追加されたタスクは一覧で表示されます。
- チェックボックスにチェックが入っているタスクが1件以上ある場合のみ、「完了」「削除」ボタンが表示されます。
- 各タスクの左端にあるチェックボックスにチェックを入れた状態で「完了」ボタンを押すと、対象タスクに取り消し線が適用されます。
- 各タスクの左端にあるチェックボックスにチェックを入れた状態で「削除」ボタンを押すと、対象タスクを削除できます。
- タスクのテキストをクリックすると、そのタスクを編集することができます。

## 使い方

### タスクの追加

1. `todo-app/index.html` をブラウザで開きます。
2. 入力欄にタスクを入力します。
3. 「追加」ボタンをクリックします。
4. タスクがリストに表示されます。

### タスクの削除

1. 削除したいタスクの左端にあるチェックボックスをクリックします。
2. チェックが1件以上ある場合に表示される「削除」ボタンをクリックします。
3. チェックの入ったタスクが削除されます。

### タスクの完了

1. 完了したいタスクの左端にあるチェックボックスをクリックします。
2. チェックが1件以上ある場合に表示される「完了」ボタンをクリックします。
3. チェックの入ったタスクに取り消し線が適用されます。

### タスクの編集

1. 編集したいタスクのテキスト部分をクリックします。
2. 編集フォームが表示されるので、テキストを修正します。
3. 「編集」ボタンをクリックするとタスクが更新されます。
4. 「キャンセル」ボタンをクリックすると、編集を中止できます。

## ファイル構成

- `index.html`: 画面の構造を定義
- `todo-list.js`: タスクの追加・削除・編集のロジックを実装
- `README.md`: このドキュメント
