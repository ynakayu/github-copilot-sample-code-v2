# ToDoアプリ

JavaScriptで作成したシンプルなToDoアプリです。

## 概要

- 入力欄にタスクを入力して「追加」ボタンを押すと、タスクがリストに追加されます。
- 追加されたタスクは一覧で表示されます。
- 各タスクの左端にあるチェックボックスにチェックを入れた状態で「削除」ボタンを押すと、対象タスクを削除できます。

## 使い方

### タスクの追加

1. `todo-app/index.html` をブラウザで開きます。
2. 入力欄にタスクを入力します。
3. 「追加」ボタンをクリックします。
4. タスクがリストに表示されます。

### タスクの削除

1. 削除したいタスクの左端にあるチェックボックスをクリックします。
2. ページ上部の「削除」ボタンをクリックします。
3. チェックの入ったタスクが削除されます。

## ファイル構成

- `index.html`: 画面の構造を定義
- `todo-list.js`: タスクの追加・削除のロジックを実装
- `README.md`: このドキュメント
